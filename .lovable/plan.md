# Plan: Default Modern Email Template & Separated Passenger Serial Numbers

Set the "Modern" email variant as default for all automated booking emails (creation and confirmation) and update templates to show passenger names as a numbered list.

## User Review Required
> [!IMPORTANT]
> The "Modern" email template includes a "Submit Payment" button. If payments aren't handled through the portal, this button will just be decorative or can be linked to your bank details page.

## Proposed Changes

### 1. Update Email Templates Logic
- Modify `src/lib/agent-bookings.functions.ts` to use a refined HTML structure based on the "Modern" template design for both `notifyBookingCreated` (admin notification and agent copy) and `promoteConfirmedBooking` (confirmation email).
- Implement a helper function to split the `passenger_names` string and format it as a numbered list (1., 2., 3...).

### 2. Update Admin Email Preview Component
- Modify `src/components/admin/email-preview/BookingEmailPreview.tsx` to set the default state of `variant` to `'modern'`.
- Update the passenger rendering logic in the "Modern" (and other) variants to display names with serial numbers.

### 3. Database Functions (Optional)
- Check if any database triggers or functions generate emails directly (unlikely based on codebase structure, but will verify).

## Technical Details
- The `passenger_names` field is a newline-separated string in the database.
- The "Modern" template uses a specific color palette: Navy (`#0b2545`), Gold (`#C5A059` or similar), and Emerald for success states.
- Serial numbers will be generated by splitting the passenger string: `names.split('\n').map((n, i) => `${i + 1}. ${n}`).join('\n')`.
